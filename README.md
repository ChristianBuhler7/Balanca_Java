# Balanca_Java

Este projeto consiste em um sistema web desenvolvido para facilitar o gerenciamento de uma construtora, permitindo o cadastro, a consulta, a alteração e a exclusão de informações relacionadas às obras, suas fases, engenheiros, funcionários e usuários. O sistema foi desenvolvido utilizando Java e banco de dados, contando com uma interface simples e funcionalidades de autenticação e gerenciamento de registros.
